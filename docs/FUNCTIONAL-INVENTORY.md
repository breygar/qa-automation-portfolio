# Functional Inventory

**Analysis date:** 2026-09-10
**Environment:** Public production-like practice site at `https://automationexercise.com`
**Status:** Phase 2 analysis baseline; current implementation status is tracked in the traceability
matrix.

## Evidence model

- **Observed:** Confirmed through low-volume anonymous page retrieval or a non-mutating request.
- **Documented:** Described by the site's official Test Cases or API Testing pages.
- **Assumption/open question:** Requires a controlled stateful session or stakeholder clarification.

No accounts, orders, reviews, subscriptions, or contact messages were created during analysis.

## Confirmed dependencies

- The public Automation Exercise environment and its live catalog data.
- Browser session/cookie state for cart and authenticated workflows.
- Disposable account data for registration, authenticated checkout, and account API coverage.
- Third-party page assets/advertising that can affect timing but are not product assertions.

There is no direct database access, stable seed service, environment reset, or documented endpoint
for deleting contact messages, subscriptions, reviews, carts, or orders.
